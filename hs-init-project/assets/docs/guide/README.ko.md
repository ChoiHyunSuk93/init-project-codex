# 프로젝트 가이드

이 문서는 사람이 실제로 따라야 하는 설치, 실행, 테스트, 빌드, 배포와 운영 guide의 진입점이다.
규칙, 작업 로그, 단순 파일 목록은 guide로 복제하지 않는다.

## 확인된 워크플로

- `HS_INIT_SEMANTIC_TODO`: 실제 manifest, task, CI, source 또는 기존 문서에서 확인한 사용자 워크플로와 진입점을 기록한다. 확인된 workflow가 없으면 그 사실과 근거를 명시한다.

## 가이드 인덱스

- `HS_INIT_SEMANTIC_TODO`: 기존 guide를 실제 Markdown link와 독자 관점 설명으로 연결한다. 추가 guide가 아직 필요 없으면 이유를 명시한다.
