# Implementation Record Instructions

This directory stores user-facing implementation history after acceptance criteria and required verification pass.
Keep plans, handoffs, and progress logs under [`subagents_docs/`](../../subagents_docs/AGENTS.md).

## Record Policy

- After a material implementation change reaches `PASS`, add a new record under the nearest concern-based category.
- Do not pre-create empty categories or placeholder implementation records during initialization.
- Keep sequential `NN-name.md` filenames within each category.
- Preserve older records as history unless correcting an error, broken link, invalid verification claim, or explicit user request.
- Do not create weak catch-all categories such as `misc`, `general`, `notes`, `other`, or `briefings`.

## Required Content

- `Summary`
- `Changes`
- `Reason`
- `Verification`
- `Related Rules`

Keep records concise and human-readable, and separate exact verification commands from observed results.
